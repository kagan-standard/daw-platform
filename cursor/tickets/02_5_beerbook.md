Summary
Transform BeerBook from a basic rating app into a full-featured beer discovery platform with comparative ratings (YG Exchange), geotagging, venue tracking, price logging, happy hour intel, maps, social features, and mobile polish.
Workstreams

Schema & Database Expansion — new tables (venues, happy_hours, price_logs, reactions), new columns on ratings, updated views
API Expansion — 25+ new endpoints covering beers, venues, prices, happy hours, exchange rates, deals, activity, map, uploads
Rating Form Upgrade — star input, beer autocomplete, YG slider, geotag capture, photo upload, price logging, toasts
The YG Exchange — trading floor view, cross-rate calculator, portfolios, arbitrage alerts, YG badges everywhere
Beer Map & Venues — Leaflet.js map, venue pins, beer trails, venue detail pages, happy hour tracking, "Best Beer Near Me"
Dashboard Polish & Stats — enhanced stats cards, new charts, activity feed, better empty states, time-bounded leaderboards
Social & Discovery — user profiles, beer detail pages, cheers reactions, advanced filtering, delete own reviews
Mobile & PWA — responsive audit, PWA manifest, skeleton loaders, keyboard shortcuts, toast system
Infinite Scroll & Performance — paginated loading, style tooltips, client-side data caching

Key Features

YG Exchange: Comparative beer rating system using Yuengling Golden Pilsner as reserve currency
Geotagging: Location capture on ratings, venue auto-creation, beer trail maps
Price Tracking: Log beer prices at venues, happy hour specials, "Best Beer Near Me" query
Deals Engine: Find cheapest/best-rated beer nearby factoring in YG value, price, happy hours, and distance
Social: Cheers reactions, user profiles, activity feed, leaderboards
